# Wool Knitwear Leads｜羊毛针织面料获客数据库

本项目用于整理中国境内已公开涉及美利奴羊毛运动服、户外服、羊毛贴身层及羊毛针织面料的品牌和制造企业线索。

## 文件
- `leads.csv`：客户线索主表，可用 Excel/WPS 打开，也可由 Python 读取。
- `wool-knitwear-leads.xlsx`：带筛选、冻结首行和字段说明的工作簿。

## 使用原则
1. 仅记录公开可核实的企业/品牌信息及公开商务联系方式。
2. 每条线索保留来源链接；联系前再次核实主体、联系方式、产品在售状态和采购需求。
3. “强/中/初步线索”表示证据充分程度，不代表采购意愿。
4. 企业规模只按公开披露信息标注；未披露则标为未公开，不推断。
5. 一体化制造企业可能是同行或合作方，不应自动视为面料采购客户。
6. 不录入私人手机号、私人邮箱或非公开个人资料。

## 后续开发路线
- 第一步：人工核验公司主体、官网、公开商务联系方式。
- 第二步：增加采购联系人部门、面料类型、克重/成分需求、年采购量（仅在对方公开或沟通确认后填写）。
- 第三步：开发 Python 去重、来源检查、跟进提醒和客户筛选功能。
- 第四步：再考虑自动发现新线索；自动发现结果必须人工复核，不能将搜索摘要直接当成事实。
